# 🌟 星光鎮：夢幻小魔女與飛天小貓 (Starlight Town)

專為 8 歲國小低年級設計的 2.5D 等角視角繪本風冒險、模擬餐廳經營與益智小遊戲。

## 📖 1. 遊戲故事背景與世界觀
在充滿歡笑與和煦陽光的 **「星光鎮（ㄒㄧㄥ ㄍㄨㄤ ㄓㄣˋ）」**，鎮中心彩虹塔上的「彩虹水晶」突然散落成無數個 **「星光碎片（ㄒㄧㄥ ㄍㄨㄤ ㄙㄨㄟˋ ㄆㄧㄢˋ）」**。
玩家扮演初到小鎮的 **「夢幻小魔女公主」**，帶著專屬萌寵夥伴 **『飛天星光小貓』**，騎著腳踏車、酷炫粉紅機車、粉紅敞篷車與魔法獨角獸穿梭在大街小巷、夢幻森林與繽紛海岸之間。透過幫助居民解開小遊戲任務、採集食材並經營「星光餐廳」，收集星光碎片讓小鎮重回歡樂與色彩！

## ✨ 2. 核心特色
- **🎨 2.5D 等角視角繪本世界**：主角與載具佔畫面高度約 $\frac{1}{6}$ 黃金比例，支援雙圈彩色觸控搖桿、鍵盤 `WASD` / 方向鍵與點擊地面移動。
- **🔤 國小低年級直式注音 UI + 甜美女聲語音朗讀 (TTS)**：所有對話、任務指引與道具均附帶國字右側直排注音，並有右上角 `🔊 語音朗讀` 按鈕。
- **🏪 模擬城市雙重經營系統（星光餐廳）**：
  - **🌟 魔法親自經營**：劃圈擠冰淇淋、堆疊草莓、灑上星光糖粉製作「彩虹星光草莓冰淇淋帕菲」（享 1.5 倍金幣 + 雙倍星星）。
  - **🐾 寵物代理經營**：出門冒險時由飛天小貓戴高帽自動賣餐給動物 NPC，定時彈出收益通知並累積金幣寶箱。
  - **🏙️ 餐廳擴建升級**：聘請「麵包兔」（供應小麥粉）、「水手鴨」（運送鮮奶）並擴建「露天彩虹陽傘桌椅」。
- **🧠 階梯式高難度小遊戲關卡**：
  - `1-1 冰淇淋快遞`：【空間與反應】三軌道動態跑酷 + 跳躍斜坡
  - `1-2 幾何地磚`：【幾何與空間】3D 旋轉翻轉拼圖 + 紅光與藍光合成紫光通電
  - `1-3 失蹤的小貓`：【動態記憶】5 音符花朵序列記憶 + 180° 旋轉位置干擾
  - `2-1 貝殼水果派對`：【數理邏輯】魔法天平三數相加等於 15（如 $4+5+6=15$）
- **👗 屋內換裝小屋系統**：左側 30% 支援 360° 旋轉舞台與轉圈歡呼，右側 70% 提供五大部位分頁（頭飾/衣服/鞋子/翅膀/寵物飾品）與底部 7 色調色盤。
